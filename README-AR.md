# BW Foot — مشروع Android

هذا الغلاف يشغّل موقع BW Foot الحالي داخل تطبيق Android ولا يعدّل الموقع أو قاعدة بياناته.

## إنشاء APK
1. أنشئ مستودع GitHub جديدًا باسم `bw-foot-android` واجعله Public أو Private حسب تفضيلك.
2. ارفع كل محتويات هذا المجلد إلى الفرع `main`.
3. افتح **Actions** ثم **Build BW Foot APK** واضغط **Run workflow** (أو انتظر البناء بعد دفع الملفات).
4. بعد نجاح البناء، افتح تشغيل workflow ونزّل artifact باسم `BW-Foot-Android-APK`، ثم استخرج `app-debug.apk`.
5. انقل APK إلى الهاتف وثبّته مع السماح بالتثبيت من هذا المصدر عند الطلب.

هذا ملف اختبار موقّع بمفتاح debug تلقائيًا، مناسب للتثبيت المباشر وليس إصدارًا للنشر على Google Play. يحتاج التطبيق إلى الإنترنت ويحمّل الموقع من عنوانه الحالي؛ بيانات المنصة تبقى على خدمتها الحالية.
